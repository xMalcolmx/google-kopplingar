Integritetspolicy

Gäller en privat app som bara används av sin ägare. Senast uppdaterad 26 september 2026.

  • Appen kommer bara åt ägarens egna data i Googles tjänster, och bara med ägarens samtycke.
  • Inloggningsuppgifter sparas bara lokalt hos ägaren.
  • Data säljs inte, delas inte med tredje part och används inte för reklam.
  • Användningen av data från Googles API:er följer Google API Services User Data Policy, inklusive kraven på begränsad användning (Limited Use).
  • Åtkomsten kan återkallas när som helst på myaccount.google.com/connections.

This private app is used only by its owner. It accesses only the owner's own Google data, with the owner's consent. Credentials are stored locally. No data is sold, shared with third parties or used for advertising. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/connections.
